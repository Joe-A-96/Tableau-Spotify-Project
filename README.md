# Tableau-Spotify-Project

## 🎶 Spotify Breakdown: Music Listening Analysis (Tableau)

**An interactive data visualization project built in Tableau to explore and analyze personal or public music listening trends, habits, and preferences from a Spotify dataset.**

***

## 💡 Project Goal

The primary objective was to transform raw streaming data into a clear, interactive visual story. This project allows users to gain insights into listening behavior, including:

1.  **Genre and Artist Distribution:** Identifying the most popular genres and top-performing artists.
2.  **Time Series Analysis:** Tracking changes in listening volume or genre preference over time.
3.  **Key Metrics Breakdown:** Visualizing metrics like play counts, track duration, or average song attributes (e.g., "danceability," "energy").

***

## 🛠️ Key Tableau Skills Demonstrated

This project showcases advanced data visualization and dashboarding techniques within the Tableau environment.

### Data Modeling & Preparation

* **Data Source Connection:** Connected and prepared data from the source (e.g., CSV, SQL, or Spotify's API data) for analysis.
* **Data Joins/Blends (Implied):** Structured the data model using **Joins** or **Data Blending** if multiple tables (e.g., tracks and artist metadata) were involved.

### Interactivity & Dashboard Design

* **Parameters:** Implemented **Parameters** to allow users to dynamically switch between different metrics, time periods, or visualization types.
* **Filters and Actions:** Utilized global filters and **Dashboard Actions** (Filter, Highlight) for seamless interaction between different charts and sheets.
* **Dashboard Layout:** Designed a clean, user-friendly, and responsive dashboard layout suitable for presenting complex insights clearly.
* **Visual Best Practices:** Employed appropriate chart types and color palettes to ensure data clarity and visual appeal.
